# ADR-011：自动发现、一次性配对与平台凭证

状态：实现；2026-09-30。macOS 功能验证通过，Windows/Linux 的原生运行验证按本轮要求未执行。

## 身份和发现

共享 `neonmix-identity` 使用锁定的 `mdns-sd 0.21.4` 注册和浏览 `_neonmix._tcp.local.`。TXT 只发布 `hub_id`、房间名称、协议版本、能力；端口来自 SRV。服务实例和 hostname 使用 Hub UUID 与公开证书摘要前缀；相同房间名称可以共存；相同 UUID 的异钥候选也保持独立，摘要前缀只用于名称分离，不授予信任。实际 DNS 冲突由库的探测/改名处理。通配监听在所有适用接口发布，具体地址监听只在对应接口发布；接口地址每秒检查一次。浏览保留独立服务实例及所有解析地址，支持变更、goodbye 删除和主动 SRV/A/AAAA 活性验证。

发现结果始终未认证；客户端按邀请/已配对资料中的稳定 UUID 筛选，再在有界并发中验证保存的证书和 HTTPS 身份响应；候选解析后立即验证，不等待整个浏览窗口。IPv6 链路本地地址保留 scope，通过受控 DNS override 交给 HTTP，并直接连接该 SocketAddr 建立 WSS；媒体沿实际已认证地址保留 scope。不会因为同名、TXT 或 IP 一致而信任候选。

TLS 1.3 使用精确 DER 证书固定校验，并正常验证 CertificateVerify 签名。所保存的自签名证书是身份，不依赖地址对应的 SAN 或系统 CA。证书的重签/换钥均要求显式新邀请和新凭证资料；不自动接受“同公钥的新证书”，也没有跳过签名检查的信任路径。相同证书但不同 Hub UUID 同样拒绝。HTTPS 禁止代理、跨址重定向和 HTTP 降级。

## 一种首次配对机制

采用可复制的一次性邀请 JSON：协议版本、Hub UUID、名称、证书、邀请 UUID、244 bit OS 随机秘密及到期时间。用户从已认证的 Hub 管理员取得该文件，在另一设备使用 `pair`；桌面操作无需摄像头。Unix 文件以 0600 创建，Windows 以受保护的仅所有者 DACL 排他创建；CLI 的结果/日志不输出邀请秘密。邀请不发布在 mDNS。

Hub 仅管理员可开启/取消邀请；最大 16 条，期限 1–300 秒，按单调时钟判断期限。服务仅保存秘密的 SHA-256，比较采用常量时间；未完成邀请不落盘，重启即失效。领取 API 全局最多 32 次/秒，请求体最多 16 KiB，客户端不能指定角色。客户端在平台库先保存自己生成的长期令牌，只上传摘要；Hub 使用 E04 的管理员 Principal 和持久化注册事务固定授予 Member。角色来源始终在服务端。

同一邀请只登记一个设备。完成期限内相同完整请求返回原设备；另一个请求返回 409。落盘失败不消耗邀请或注册身份。已撤销的签发管理员不能继续签发未完成信任；已撤销设备不能借旧邀请再次取得成功响应。响应丢失时，客户端复用已存令牌和请求 UUID；先验证实际认证是否成功，再补登记或完成本地 `pending` 状态。因此 Hub 在登记后重启也能恢复已落盘的结果，且不会因重试新增身份。

## 凭证和生命周期

`setup` 创建平台保护的正式 Hub/管理员资料；`pair` 创建正式 Sender 资料。元数据保存公开证书、稳定 UUID、凭证库引用、登记请求 UUID/设备 UUID 和 pending 标记；不保存长期令牌或私钥。`keyring 3.6.2` 分别使用 macOS Keychain、Windows Credential Manager 和 Linux Secret Service。不可用、锁定或条目丢失均报错，不静默选择明文。Hub 权威状态仍使用既有原子 JSON，凭证只有摘要；本轮不另起 SQLite 状态权威。

原 `init` 的明文文件仅为明确标记的实验 provision，兼容原探针；正式流程不会调用它。初始配置有独占 setup marker，错误回滚只清理自己创建的元数据和平台条目，避免覆盖其他初始化结果。

配对不创建会话，不启动采集或广播。Sender 只有显式 `send` 开始发送，停止或终端故障后不自动发起新媒体会话。WSS 可以在网络中断后重新发现、验证、取快照并订阅；撤销立即停止控制和活动媒体，并在 Hub 重启后继续拒绝旧令牌。E04 的管理员断开、重新允许与撤销仍是不同操作。`forget` 删除本地平台令牌和资料；对 Hub 权威配对关系的撤销使用管理员 `revoke` 命令。

接口、操作与证据见 [E05](../E05.md)。依赖 API 来源：[mdns-sd](https://docs.rs/mdns-sd/0.21.4/mdns_sd/)、[keyring](https://docs.rs/keyring/3.6.2/keyring/)。桌面可视流程属于 E07；跨机性能和其他平台运行结果不在本轮 macOS 功能证据之内。
