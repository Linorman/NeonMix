# E07 桌面产品与后台

实现日期：2026-10-01。依据完整开发计划 §4.7、设计方案 §8、媒体控制合约与输出绑定合约。桌面已从设备诊断窗口扩展到五个功能页面；UI、后台和音频执行进程相互独立。本轮运行验证限定 macOS，Windows/Linux 实机与完整辅助功能验收仍待补。

## 使用

先在项目内准备原生媒体依赖，再构建同目录的四个程序。产品运行不需要 Python：

```sh
tools/dev python3 tools/prepare_gstreamer.py
tools/dev cargo build --workspace --release --locked
tools/dev target/release/neonmix-desktop --state-dir .local/desktop
```

首次打开会启动独立 `neonmix-background`，状态默认放在项目内 `.local/desktop`。已存在的后台会被复用；不会因为 UI 重新打开而自动开始共享或发送。正式 Hub/Sender profile 使用文件凭证，元数据 JSON 仅存公开身份与 UUID 引用，秘密以明文保存于相邻 .credentials 并由当前用户私有权限保护。

Hub 页面填写房间名，选择固定身份的实体输出，按需播放 −36 dBFS、两秒测试音，再创建并开始共享。设置变更需先停止共享，保留 Hub UUID 与凭证。邀请创建后默认遮挡，可复制到目标 Sender；有效期 120 秒，可取消，使用后需生成新的邀请。

Sender 页面发现房间、粘贴邀请并配对，再主动添加虚拟输出。虚拟设备须具备 E06 原生能力：macOS/Windows 需要已安装驱动，Linux 使用独立本地节点 owner。用户在系统声音设置选择该输出；发送范围明确为选到这个虚拟输出的所有应用声音。程序不改变系统默认输出，不默认采集麦克风。

关闭窗口保持后台；macOS Cmd+W 隐藏窗口，托盘“打开 NeonMix”恢复界面。停止发送结束 Sender；停止共享结束 Hub；“退出后台”及 macOS Cmd+Q 的确认操作结束本实例全部音频。取消确认不会结束音频。UI 崩溃后重新启动相同状态目录即可读取实际状态。

管理员断开设备后，重新允许只恢复权限，Sender 需要手动开始。永久撤销后，在 Sender 选择“删除本机配对”，删除旧凭证并禁用绑定，再使用新邀请配对。同 Hub 可显式重新启用原绑定；换 Hub 必须删除旧绑定并重新添加。没有自动恢复已明确停止、禁止或撤销的发送。

## 页面与契约

| 页面 | 能力与边界 |
|---|---|
| Hub 设置 | 房间命名、实体输出选择、低音量测试音、开始/停止共享、创建/取消/复制一次性邀请 |
| Sender | 不可信候选发现、固定身份配对、绑定添加/改名/启用/禁用/删除、范围与目标显示、明确停止、删除本机配对 |
| Mixer | 每路 Peak/RMS、−96…+12 dB 增益、Mute/多 Solo、管理员断开、总音量/静音、输出可用性与 limiter 增益 |
| 设备管理 | 稳定身份、名称、角色、播放授权、撤销与重新允许、本地搜索和清除、原生设备身份查询 |
| 诊断 | 本地进程、采集、媒体丢包/迟到/PLC、缓冲、输出/欠载/限幅、故障类别、严格白名单脱敏导出 |

成员只能修改自己的通道，Solo 和总控需要 Controller/Admin，撤销与重新允许需要 Admin。UI 根据已认证身份及快照禁用不允许的动作，服务器仍是最终裁决。管理员禁止、未知或过期权限不能作为可发送状态。

变更携带权威 revision，冲突后刷新并提示核对重试，不盲目覆盖。后台刷新不禁用输入和增益拖动；切换身份/地址后丢弃旧请求结果。慢查询与用户动作分开；本地停止可中断只读查询。快速开始后停止会等待在途 Start 的结果并最终再 Stop，防止旧 Start 在停止确认后重新发送。

所有确认使用同一 Modal。取消后在下一帧将键盘焦点返回当前页导航，避免菜单或已消失设备留下无效焦点。中文输入、键盘基础与 AX 控件标签已接入 egui/accesskit；完整 VoiceOver 听读与真实中文输入法组合矩阵属于后续验收。

## 真实电平与延迟口径

`diagnostics.meters` 由实时 Mixer 的预分配观测窗口发布，音频线程不分配、不加锁。窗口为内部 48 kHz 的 2,400 帧，即最新完整 50 ms；UI 约每秒刷新一次诊断。Peak 为双声道最大绝对样本，RMS 为双声道均方根；每路在该路增益/Mute/Solo 之后、总控之前，输出在总控和 limiter 之后。`limiter_gain` 是窗口最小线性增益。

发布时用有界原子快照保护电平和 stream ID 的一致性。槽位复用、重开和输出不可用不会显示旧流电平；无音源窗口归零，静音仍保留实际 5 ms 渐变。采集页的 Peak 则是本次会话累计最大值，明确标注，不能冒充近期电平。

Mixer 队列估计按帧数 / 48 kHz 换算，只代表该缓冲段。网络、缓冲、设备与模拟端不能被合并成伪造的“已测端到端声音延迟”。未知、过期、无数据与故障分别显示。

脱敏导出固定写入私有状态目录 `diagnostics-redacted.json`，只保留定义好的数值、布尔与 null 字段，剔除任意字符串、身份、名称、地址、路径、证书、令牌、私钥与凭证引用。实际错误文字不会进入导出。
